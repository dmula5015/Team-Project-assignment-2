# College Student Planner

CIS 332 Web Programming project by Daouda Traore.

## Pages
Dashboard (`index.html`), My Classes, Assignments, Upcoming Due, About.

## Running locally
Open `index.html` in a browser. Data is stored in that browser using localStorage.

## Publish with GitHub Pages
1. Create a public GitHub repository named `student-planner`.
2. Upload all files and folders from this directory into the repository root (not a nested `student-planner` folder).
3. In the repository go to Settings > Pages. Under Build and deployment choose **Deploy from a branch**, branch **main**, folder **/(root)**, then Save.
4. Once deployment completes, open `https://YOUR-USERNAME.github.io/student-planner/`.
5. Paste your actual working URL into the PDF report before submitting.

## Current scope
HTML5, external CSS3, vanilla JavaScript, localStorage; React is planned but not implemented in this draft. No backend or cross-device sync. Sample data loads only on first use.
